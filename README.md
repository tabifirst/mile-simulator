# 1マイル単価シミュレーター

特典航空券を利用する際、1マイルが何円相当になるかを算出できるシミュレーターです。比較リストに複数追加すると、並べて比較検討できます。

## 計算式

```
マイル価値 ＝（有償運賃 − 特典時の燃油サーチャージ/諸税）÷ 必要マイル
```

## マイル価値の判断目安

| 1マイルあたり | 判定 |
|---|---|
| 1円未満 | 割に合わない |
| 1〜2円 | 標準的 |
| 3〜4円 | お得 |
| 5〜9円 | かなりお得 |
| 10円以上 | 最高！ |

## 使い方

`index.html` をブラウザで開くだけで動きます。ビルドやインストールは不要です。
入力内容と比較リストはブラウザ（localStorage）に保存されます。

## GitHub Pages で公開する

1. このリポジトリに `index.html` を置いてプッシュ
2. リポジトリの **Settings → Pages** を開く
3. **Source** を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にして保存
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます
